Conectar câmera / Kinect

O Kinect v1 é reconhecido como câmera RGB pelo Windows. Se tiver mais de uma câmera, tente índices diferentes.

  • 1Conecte o Kinect via USB (alimentação separada necessária no v1).
  • 2Escolha o índice da câmera abaixo (normalmente 0 ou 1).
  • 3Ative a profundidade se tiver o driver freenect instalado.
  • 4Clique em Conectar.
